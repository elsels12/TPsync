# TPSync かんたん導入・完全安心ガイド
（プログラミング知識ゼロでもそのまま使える取扱説明書 v1.85）

---

## 🔰 はじめに
「コードが書けない・直せない」というご不安を解消するため、TPSyncは**プログラムの知識が一切なくても、直感的なタップ操作だけで安心して使えるように設計・検証**されています。

専門知識は一切不要です。以下の手順に沿ってご利用ください。

---

## 📱 1. アプリの開き方・スマホへの入れ方（所要時間：1分）

### ⚠️ 最重要：サーキットに行く前の準備
オフライン機能（電波ゼロでの起動・保存）を利用するには、**「ご自宅などの電波が繋がる場所で、事前に一度ブラウザで開いてホーム画面に追加しておく」** 必要があります（初回アクセス時にアプリ本体が自動的にスマホ内へ保存されます）。

### ① iPhone（Safari）の場合
1. 配布された `index.html`（またはご自身のGitHub Pages等の公開URL）を開きます。
2. 画面下部の中央にある **「共有ボタン（四角から上向き矢印が出ているマーク）」** をタップします。
3. 少し下にスクロールして **「ホーム画面に追加」** をタップします。
4. 右上の **「追加」** をタップします。
5. **ホーム画面にゴールドのタイヤアイコン（TPSync）が追加されます！**
   - 以降は、そのアイコンをタップするだけで通常のアプリと同じように全画面で快適に起動します。

### ② Android（Chrome）の場合
1. `index.html`（またはURL）をChromeで開きます。
2. 画面右上の **「︙（3点メニュー）」** をタップします。
3. **「ホーム画面に追加」** または **「アプリをインストール」** をタップします。
4. ホーム画面に専用アプリアイコン（Android適応型マスク対応）が追加されます。

## 🏎️ 2. サーキットでの普段の使い方（完全オフライン対応）

TPSyncは、**「電波の届かない山奥のサーキットでも絶対に止まらない」** ように作られています。

1. **空気圧を測ったら入力するだけ**:
   - 上段の「冷間 COLD」または「温間 HOT」を選び、4輪の数値をプルダウンまたは直接入力します。
   - 気温や路面温度、タイム、メモ等があれば入力します（空欄でも問題ありません）。
2. **「記録する」を押す**:
   - スマホ本体の内部領域（ローカルストレージ）に即座に安全保存されます。
   - 電波が圏外であっても何の問題もなく記録・閲覧・検索が可能です。
3. **冷間と温間の自動まとめ**:
   - 朝に「冷間」を記録しておき、走行後に「温間」を記録して「直前の走行枠にまとめる」を選ぶと、1つのカードに冷温間データが綺麗に合体します（12時間以内の走行枠に対応）。

## ☁️ 3. Googleスプレッドシート連携（チーム・仲間とのデータ共有）

スプレッドシート連携を行わなくても単体で完全動作しますが、**「PCで一覧を見たい」「仲間と走行データを共有したい」** 場合は以下のステップで連携できます。

### 📌 代表者が最初の1回だけ行う作業（約2分）
1. Googleドライブで新しい **Googleスプレッドシート** を1つ作ります（名前は何でもOK、中身は空で大丈夫です）。
2. 上部メニューの **「拡張機能」** → **「Apps Script」** を開きます。
3. 画面に最初から書かれている英語をすべて消して真っ白にします。
4. 同梱の `Code.gs`（またはTPSyncアプリ上部の「共有使用」画面にあるコード）をコピーして、Apps Script画面にそのまま貼り付けます。
5. 上部の **フロッピーマーク💾（保存）** を押します。
6. 右上の青い **「デプロイ」** → **「新しいデプロイ」** を押し、歯車マーク⚙で **「ウェブアプリ」** を選びます。
   - 次のユーザーとして実行：**「自分」**
   - アクセスできるユーザー：**必ず「全員 (Anyone)」を選ぶ**
7. **「デプロイ」** を押し、Googleのアクセス承認を完了すると、**ウェブアプリのURL** が発行されます。
8. そのURLをコピーし、TPSyncの「共有使用」枠に貼り付けて **「保存」** を押せば完了です！

### 👥 仲間への共有と同期の仕組み
- **共有方法**: 代表者が発行されたURLをLINE等で仲間に送ります。仲間は自分のTPSyncの「共有使用」にそのURLを貼って保存します。
- **同期のタイミング**:
  - **送信（Push）**: 自分が記録・編集・削除した内容は、自動的にスプレッドシートへ送信されます（オフライン時は未送信キューに保持され、通信復帰時に自動再送されます）。
  - **受信（Pull）**: 他のメンバーが新しく記録したデータを自分のスマホに取り込むには、画面右上の **「更新（ぐるぐるアイコン）」** をタップしてください。最新データが取得され、ローカルへ安全にマージされます。
- **スプレッドシート上の数値集計**:
  - 空気圧（M〜T列）や気温・路面温度（E〜F列）は数値型として正しく記録されるため、スプレッドシート側で `=AVERAGE(...)` やグラフ作成を行うことも可能です。

## 🌐 4. GitHub Pages で公開する場合の推奨構成

GitHubの公開リポジトリでPWAとして配信する場合、リポジトリに配置するファイルは以下の8ファイルが推奨されます。

| ファイル名 | 役割 | 備考 |
| :--- | :--- | :--- |
| `index.html` | アプリ本体 (v1.85) | 必須 |
| `manifest.json` | PWA設定ファイル | 必須 |
| `sw.js` | オフライン制御 (v1.85) | 必須（HTTPキャッシュバイパス対応） |
| `favicon-32x32.png` | ブラウザタブ用アイコン | 必須 |
| `apple-touch-icon.png` | iPhoneホーム画面用アイコン | 必須 |
| `icon-192.png` | アプリアイコン（通常表示用） | 必須 |
| `icon-512.png` | アプリアイコン（高解像度用） | 必須 |
| `icon-512-maskable.png` | Android丸型マスク用アイコン | 必須（白縁防止対応） |
| `README.md` | リポジトリ説明書 | 任意（SWキャッシュ対象外） |
| `Code.gs` | スプレッドシート用スクリプト | 任意（SWキャッシュ対象外） |

- **PWAの更新（最新版の反映）について**:
  即時起動（Stale-While-Revalidate）設計により、アプリのコードを更新した際は、裏側で最新版をダウンロードし、**次回の起動時（または再読み込み時）に新バージョンが自動適用**されます。

## 🛡️ 5. データ保護と運用の注意点

現場でのトラブルを未然に防ぐため、以下の運用ルールを推奨いたします。

1. **手動バックアップ（ファイル保存の推奨）**:
   - アプリ上部の「バックアップ・復元」から **「バックアップを保存」** を押すと、全データが入ったJSONファイルがスマホに保存されます。走行会の終了後や遠征の前などに自分宛てのLINEやメールへ送っておくと最も確実です。
2. **バックアップ取り込みと最新データの保護**:
   - バックアップを取り込む際、現在の記録よりも古いデータで新しい記録が巻き戻されることはありません（最新日時が優先されます）。
   - 手動で取り込んだ記録はローカル未同期フラグによって保護され、同期（更新ボタン）を押しても勝手に削除されることなくスプレッドシートへ安全にアップロードされます。
3. **URL管理の注意**:
   - スプレッドシート連携URLを知っている人はデータの読み書き・削除が可能です。URLは信頼できるチームメンバー内でのみ共有してください。
   - スプレッドシート側の行を手動で削除した場合、同期によって各端末からも削除が反映されますのでご注意ください。

## ❓ 困ったときは？（Q&A）

- **Q: 操作を間違えて変な数値を記録してしまった！**
  - **A**: 各履歴カードの右下にある **「編集 EDIT」** を押せば、いつでも数値を直せます。不要な場合は **「削除」** で消せます（クラウド側も自動で正しく更新・削除されます）。
- **Q: 複数の車を使い分けたい**
  - **A**: 画面上部の「車両切替」プルダウンからいつでも愛車を追加・切り替えできます。車ごとにデータが混ざることなく綺麗に分かれます。
- **Q: 山奥のサーキットで電波が繋がらない時は？**
  - **A**: 事前に一度開いておけば、電波がゼロでもアプリは即座に起動し、ローカルに即時保存されます。電波が戻った際に「更新」を押すか、自動再送によってクラウドへ反映されます。
