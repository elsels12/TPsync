# TPSync Ver1.00

タイヤ空気圧ログ（冷間／温間）。スマホで完全オフライン動作。使い方はアプリ内の「ガイド＆設定」に書いてあります。

## ファイル
| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（GAS用コードも内蔵） |
| `sw.js` | オフライン用 |
| `manifest.json` | ホーム画面追加用 |
| `icon-192.png` / `icon-512.png` / `icon-512-maskable.png` | アイコン |
| `Code.gs` | スプレッドシート連携用（GASに貼る。アプリ内のコードと同じ） |

## 更新手順
1. 上のファイルをGitHubに全部上書きアップロード
2. アプリを一度完全に閉じて開き直す（古い画面が出るとき）
3. `Code.gs` が変わったときだけ、GASに貼り直して **「新バージョン」でデプロイ**（保存だけでは反映されません）

## 困ったとき
- 連携がおかしい → 「共有使用」の「🩺 接続診断」の結果を見る
- 管理者の合言葉は GAS のスクリプト プロパティ `DELETE_KEY`（半角英大文字）
- GASのURLは合言葉と同じ扱い。他人に見せない
