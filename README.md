# TPSync かんたん導入・完全安心ガイド
（プログラミング知識ゼロでもそのまま使える取扱説明書 v1.87）

---

## 🔰 はじめに
「コードが書けない・直せない」というご不安を解消するため、TPSyncは**プログラムの知識が一切なくても、直感的なタップ操作だけで安心して使えるように設計・検証**されています。

専門知識は一切不要です。以下の手順に沿ってご利用ください。

---

## 📱 1. アプリの開き方・スマホへの入れ方（所要時間：1分）

### ⚠️ 最重要：サーキットに行く前の準備
オフライン機能（電波ゼロでの起動・保存）を利用するには、**「ご自宅などの電波が繋がる場所で、事前に一度ブラウザで開いてホーム画面に追加しておく」** 必要があります（初回アクセス時にアプリ本体が自動的にスマホ内へ保存されます）。

### ① iPhone（Safari）の場合
1. 配布された `index.html`（またはご自身のGitHub Pages等の公開URL）を開きます。
2. 画面下部の中央にある **「共有ボタン（四角から上向き矢印が出ているマーク）」** をタップします。
3. 少し下にスクロールして **「ホーム画面に追加」** をタップします。
4. 右上の **「追加」** をタップします。
5. **ホーム画面にタイヤアイコン（TPSync）が追加されます！**
   - 以降は、そのアイコンをタップするだけで通常のアプリと同じように全画面で快適に起動します。

### ② Android（Chrome）の場合
1. `index.html`（またはURL）をChromeで開きます。
2. 画面右上の **「︙（3点メニュー）」** をタップします。
3. **「ホーム画面に追加」** または **「アプリをインストール」** をタップします。
4. ホーム画面に専用アプリアイコン（Android適応型マスク対応）が追加されます。

## 🏎️ 2. サーキットでの普段の使い方（完全オフライン対応）

TPSyncは、**「電波の届かない山奥のサーキットでも絶対に止まらない」** ように作られています。

1. **空気圧を測ったら入力するだけ**:
   - 上段の「冷間 COLD」または「温間 HOT」を選び、4輪の数値をプルダウンまたは直接入力します。
   - 気温や路面温度、タイム、メモ等があれば入力します（空欄でも問題ありません）。
2. **「記録する」を押す**:
   - スマホ本体の内部領域（ローカルストレージ）に即座に安全保存されます。
   - 電波が圏外であっても何の問題もなく記録・閲覧・検索が可能です。
3. **冷間と温間の自動まとめ**:
   - 朝に「冷間」を記録しておき、走行後に「温間」を記録して「直前の走行枠にまとめる」を選ぶと、1つのカードに冷温間データが綺麗に合体します（12時間以内の走行枠に対応）。

## ☁️ 3. Googleスプレッドシート連携（チーム・仲間とのデータ共有）

スプレッドシート連携を行わなくても単体で完全動作しますが、**「PCで一覧を見たい」「仲間と走行データを共有したい」** 場合は以下のステップで連携できます。

### 📌 代表者が最初の1回だけ行う作業（約2分）
1. Googleドライブで新しい **Googleスプレッドシート** を1つ作ります（名前は何でもOK、中身は空で大丈夫です）。
2. 上部メニューの **「拡張機能」** → **「Apps Script」** を開きます。
3. 画面に最初から書かれている英語をすべて消して真っ白にします。
4. 同梱の `Code.gs`（またはTPSyncアプリ上部の「共有使用」画面にあるコード）をコピーして、Apps Script画面にそのまま貼り付けます。
5. 上部の **フロッピーマーク💾（保存）** を押します。
6. 右上の青い **「デプロイ」** → **「新しいデプロイ」** を押し、歯車マーク⚙で **「ウェブアプリ」** を選びます。
   - 次のユーザーとして実行：**「自分」**
   - アクセスできるユーザー：**必ず「全員 (Anyone)」を選ぶ**
7. **「デプロイ」** を押し、Googleのアクセス承認を完了すると、**ウェブアプリのURL** が発行されます。
8. そのURLをコピーし、TPSyncの「共有使用」枠に貼り付けて **「保存」** を押せば完了です！

### 👥 仲間への共有と同期の仕組み
- **共有方法**: 代表者が発行されたURLをLINE等で仲間に送ります。仲間は自分のTPSyncの「共有使用」にそのURLを貼って保存します。
- **同期のタイミング**:
  - **送信（Push）**: 自分が記録・編集・削除した内容は、自動的にスプレッドシートへ送信されます（オフライン時は未送信キューに保持され、通信復帰時に自動再送されます）。
  - **受信（Pull）**: 他のメンバーが新しく記録したデータを自分のスマホに取り込むには、画面右上の **「更新（ぐるぐるアイコン）」** をタップしてください。最新データが取得され、ローカルへ安全にマージされます。

## 🌐 4. GitHub Pages で公開する場合の推奨構成

GitHubの公開リポジトリでPWAとして配信する場合、リポジトリに配置するファイルは以下の8ファイルが推奨されます。

| ファイル名 | 役割 | 備考 |
| :--- | :--- | :--- |
| `index.html` | アプリ本体 (v1.87) | 必須 |
| `manifest.json` | PWA設定ファイル | 必須 |
| `sw.js` | オフライン制御 (v1.87) | 必須（HTTPキャッシュバイパス対応） |
| `favicon-32x32.png` | ブラウザタブ用アイコン | 必須 |
| `apple-touch-icon.png` | iPhoneホーム画面用アイコン | 必須（全面チタンブラック・白縁なし） |
| `icon-192.png` | アプリアイコン（通常表示用） | 必須（全面チタンブラック・白縁なし） |
| `icon-512.png` | アプリアイコン（高解像度用） | 必須（全面チタンブラック・白縁なし） |
| `icon-512-maskable.png` | Android丸型マスク用アイコン | 必須（Android丸マスク対応・白縁なし） |
| `README.md` | リポジトリ説明書 | 任意（SWキャッシュ対象外） |
| `Code.gs` | スプレッドシート用スクリプト | 任意（SWキャッシュ対象外） |

- **PWAの更新（最新版の反映）について**:
  即時起動（Stale-While-Revalidate）設計により、アプリのコードを更新した際は、裏側で最新版をダウンロードし、**次回の起動時（または再読み込み時）に新バージョンが自動適用**されます。

## 🛡️ 5. 技術仕様とエッジケース対策の解説

現場での長期運用や多人数共有において生じうるエッジケースに対し、以下の安全対策が組み込まれています。

1. **クラウド0件時の全消去防止フェイルセーフ（最後の1件の削除仕様）**:
   - スプレッドシートの行を手動で全削除した場合や、誤って空のスプレッドシートを接続した場合、**誤消去事故防止のフェイルセーフとして、アプリ側の全件削除同期はスキップされ手元の全記録が保護**されます。端末側の最後の1件を削除したい場合は、アプリ内の「削除」ボタンから行ってください。
2. **手入力行の完全内容ベース安定ID**:
   - スプレッドシート上で直接手入力されたID空行に対しては、行番号ではなく「日時＋車両名＋タイム＋空気圧」を組み合わせた**内容固有の安定ID（`manual_...`）**を生成します。他の行が削除されて行番号がずれた場合でもIDが変化せず、二重増殖や削除の食い違いを防ぎます。
3. **スプレッドシート数式・計算領域のルール**:
   - スプレッドシートの **A〜X列** はアプリとの双方向同期領域（データ領域）です。同期処理では高速化のためメモリ上の値で一括書き戻しを行うため、A〜X列に数式を直接書き込むと計算結果の値に置き換わります。
   - 独自の `=AVERAGE(...)` 計算やグラフを作成する場合は、**Y列以降の空き列、または別シート（シート2）を作成して参照**してください。
4. **端末ストレージ（localStorage）容量上限（約5MB）と上限到達時警告**:
   - ブラウザのローカル保存（localStorage）は一般的な使用で約4,000〜5,000件（約5MB）まで耐えられます。
   - 万が一端末の容量上限に達した際は、`QuotaExceededError` を検知して画面上に「⚠️ 端末の保存容量がいっぱいです。『バックアップを保存』でファイルを書き出してください」と警告トーストを表示します。シーズン終了時や年度ごとにJSONバックアップを書き出して手元にアーカイブ保管することを推奨します。

5. **同期対象シートは「1枚目のシート」固定です（v1.87）**:
   - 集計用に別シートを作っても、データは常に1枚目のシートへ書き込まれます。
6. **履歴が空に見えない工夫（v1.87）**:
   - 記録のある車両が車両リストに無い場合は自動で補完し、新しい端末での初回同期では記録のある車両へ自動で切り替わります。現在の車両が空で他の車両に記録がある場合は、切替ボタンを表示します。
7. **通信タイムアウト（v1.87）**:
   - 電波が弱く通信が固まっても約25秒で打ち切り、未送信キューに残して次回再送します（アプリを開き直した時・オンライン復帰時にも自動再送）。
8. **バックアップ復元（v1.87）**:
   - IDの無い古いバックアップやCSVも取り込めます。復元時は、この端末で削除済みの記録も復活します。

9. **数式・数値への化け防止（v1.87）**:
   - メモや場所が「=」「+」「-」「@」で始まっても、数式として扱われず文字列のまま同期されます（`2.10` のような値も数値に変わりません）。
10. **手入力行（IDなし）の編集・削除（v1.87）**:
   - スプレッドシートで手入力した行も、アプリで編集すると同じ行が更新され、削除も正しく反映されます（行が増えたり、削除した行が復活したりしません）。
11. **車両名の変更は全員に反映（v1.87）**:
   - 車両名を変更すると、その車両の記録がスプレッドシートと他の端末にも反映されます。車両の削除は、連携中のスプレッドシートと共有している全員の端末の記録も削除します。
12. **セキュリティの注意**:
   - GAS は「全員」に公開するため、ウェブアプリのURLを知っている人は誰でもデータを読み書きできます。URLはパスワードと同じように扱い、公開の場に書かないでください。

### 🛡️ 削除データの「ゴミ箱」一時退避＆自動消去（90日間保護）
- アプリ上から「削除」または「一括削除」を実行したデータは、メインシートから消える直前に自動的に **「ゴミ箱」シート**（存在しない場合は自動生成）へ丸ごと退避されます。
- 退避された行には「削除日時」が記録され、**90日間** 安全に保持されます。
- 90日を経過した古い削除データは、次回の削除操作時等に自動的に完全消去（クリーンアップ）されるため、シートが不要データで肥大化しません。
- **万が一の復元方法**: スプレッドシートの「ゴミ箱」シートを開き、該当行を1枚目のメインシートへコピー＆ペーストするだけで、即座にアプリ上へ復活します。

## ❓ 困ったときは？（Q&A）

- **Q: 操作を間違えて変な数値を記録してしまった！**
  - **A**: 各履歴カードの右下にある **「編集 EDIT」** を押せば、いつでも数値を直せます。不要な場合は **「削除」** で消せます（クラウド側も自動で正しく更新・削除されます）。
- **Q: 複数の車を使い分けたい**
  - **A**: 画面上部の「車両切替」プルダウンからいつでも愛車を追加・切り替えできます。車ごとにデータが混ざることなく綺麗に分かれます。
- **Q: 山奥のサーキットで電波が繋がらない時は？**
  - **A**: 事前に一度開いておけば、電波がゼロでもアプリは即座に起動し、ローカルに即時保存されます。電波が戻った際に「更新」を押すか、自動再送によってクラウドへ反映されます。
